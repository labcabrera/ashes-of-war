= Ashes of War
:toc:
:toclevels: 2
:icons: font
:source-highlighter: rouge

Ashes of War is a frontend-only companion application for a World War II tabletop wargame system.
It provides a searchable rules reference, a curated catalogue of historical units and weapons, and an army builder for composing force lists directly in the browser.

The application is deployed at link:https://aow.labcabrera.com/[https://aow.labcabrera.com/].

== Project Goals

The project is designed as a lightweight, self-contained tool for players who need quick access to game data during list building and play.
It does not require a backend, user accounts, or external APIs.
All user-created army data is stored locally in the browser.

Core capabilities include:

* Browse unit profiles, movement, armour, thresholds, weapons, and descriptions.
* Browse weapon profiles and see which units carry each weapon.
* Build and persist army lists using browser local storage.
* Use the application in English or Spanish.
* Deploy as a static single-page application.

== Local Development

Install dependencies:

[source,bash]
----
npm install
----

Start the development server:

[source,bash]
----
npm run dev
----

The local application is served by Vite, usually at:

[source,text]
----
http://localhost:5173
----

== Updating Game Data From Historical Data

Some catalogue entries store historical reference data and game-facing values in the same JSON file.
This is currently used by vehicle-like entries under `src/data/vehicles` and towed weapon entries under `src/data/towed`.

The transformation formulas live in `src/utils/conversions.ts`.
The update flow recalculates only derived fields:

* `game.movement`, when `historical.speedKmh.road` exists.
* `game.armor`, when `historical.armor` exists.

Manual balancing data is preserved, including `game.cost`, `game.organizationThreshold`, `game.casualtiesThreshold`, `game.resourceCosts`, `game.weapons`, and `game.keywords`.
The formulas are intentionally a first draft for content authors; generated values should be reviewed before committing them.

To update the JSON files in place:

[source,bash]
----
npm run update:game-data
----

To preview the files that would change without writing anything:

[source,bash]
----
npm run update:game-data -- --dry-run
----

To use the updater as a consistency check in CI or before a review:

[source,bash]
----
npm run update:game-data -- --check
----

The `--check` mode exits with an error when any derived game data differs from the current historical conversion output.
After updating data, run the normal validation commands:

[source,bash]
----
npm run test:run
npm run build
----

== Architecture Notes

Ashes of War is intentionally frontend-only.
Static game data lives in JSON files under `src/data`, domain types live under `src/types`, and route-level views live under `src/pages`.

The army builder persists user-created lists through browser local storage, keeping the application deployable as static assets without server infrastructure.
