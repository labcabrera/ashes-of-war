== Leyenda

* *Mov.* usa el formato `T/C/D carretera/campo a través/terreno difícil`, donde `T` es movimiento táctico, `C` es movimiento de crucero y `D` es movimiento rápido.
* *Org.* indica el umbral de organización.
* *Bajas/Combatientes* muestra el umbral de bajas y, para infantería, el número de combatientes.
* *Blindaje* usa el formato `F/L/R/Exp valor (mm/inclinación)` para frontal, lateral, trasero y expuesto.
