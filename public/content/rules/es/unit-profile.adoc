El perfil de una unidad reúne los valores que se utilizan durante la partida para desplegarla, moverla, resolver su resistencia al daño, usar su armamento y aplicar reglas especiales.

Este documento explica el significado de cada valor del perfil de juego. No es una lista de unidades ni una clasificación de tipos de unidad.

== Características

Las características describen cómo se comporta una unidad cuando intenta actuar bajo presión, soportar castigo o funcionar sin depender por completo de la estructura de mando.

* `Organización`: nivel establecido durante la partida que medirá la capacidad de una unidad de realizar cualquier tipo de acción.
* `Coordinación`: habilidad de una unidad para actuar de forma activa y coordinada con otras unidades. Es la que será usara generalmente para acciones ofensivas.
* `Obstinación`: capacidad de una unidad para tolerar bajas y mantener la linea cuando ante ataques enemigos.

== Valores de infantería

La infantería usa valores adicionales para representar el número de combatientes y su tolerancia a las bajas.

* *Número de integrantes*: número de individuos en la unidad. Este valor se utilizará para determinar la capacidad operativa de la unidad y su moral.

== Vehículos

* *Blindaje*: el valor que representa la el grado de protección contra armas con capacidades de penetración. Cada vehiculo tendrá cuatro valores de blindaje correspondientes a los diferentes encaramientos:

* Frontal
* Lateral
* Trasero
* Expuesto
